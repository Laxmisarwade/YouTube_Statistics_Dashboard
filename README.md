# YouTube Statistics & Performance Dashboard

## About the Project

This project is a Power BI dashboard created to analyze YouTube statistics and channel performance. The dashboard provides an interactive way to understand information related to uploads, views, subscribers, channel types, and different YouTube categories.

## Objective

The main objective of this project is to analyze YouTube channel data and present useful information through an interactive Power BI dashboard.

## Tools Used

* Power BI
* Power Query
* DAX
* CSV / Excel Dataset

## Dashboard

The dashboard contains different visualizations and analysis related to YouTube channel performance.

It includes:

* Total uploads
* Video views
* Average video views
* Subscribers by category
* Uploads by channel/title
* Channel type analysis
* Category-wise analysis
* Ranking-related analysis

## Key Insights

From the dashboard, I analyzed:

* Which categories have a higher number of subscribers.
* Which channel types have better performance.
* The number of uploads across different channels.
* Video view performance.
* The distribution of YouTube channels across different categories.

## How to Use

1. Download or clone this repository.
2. Open the `YouTube_Statistics_Dashboard.pbix` file using Power BI Desktop.
3. If required, connect or refresh the dataset.
4. Explore the dashboard using the available charts, filters, and visualizations.
